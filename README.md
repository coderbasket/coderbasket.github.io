# Coder Basket

**Discover. Explore. Share. Open Source.**

[![Website](https://img.shields.io/badge/Website-Coder%20Basket-blue)](https://coderbasket.github.io)

[Coder Basket](https://coderbasket.github.io) is a curated gallery for discovering **open-source projects, libraries, frameworks, tools, templates, and applications** across the developer ecosystem.

Whether you're building with **.NET, Flutter, AI, web technologies, or cross-platform frameworks**, Coder Basket makes it easier to find projects worth exploring.

## 🔎 Why Coder Basket?

Coder Basket is designed to make open-source discovery easier.

Instead of searching through repositories individually, developers can browse a curated collection organized around:

* **Technology**
* **Framework**
* **Platform**
* **Category**
* **Project type**

It's a place to discover new tools, learn from open-source code, and find projects that can help with your next development idea.

## 🤝 Community

Coder Basket is built around the open-source community.

Developers and contributors are welcome to submit projects and help grow the collection of useful, interesting, and high-quality open-source software.
